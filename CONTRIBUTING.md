# Contributing

Thank you for your interest in PlumTerm.

PlumTerm is **source-available**, not open source. The code is published under
the [PolyForm Strict License 1.0.0](LICENSE), which does not allow making
changes or new works based on the software, so **we cannot accept pull requests
or code contributions**.

What helps us most:

- **Bug reports and feature ideas:** please open an [issue](../../issues) with
  your operating system, the PlumTerm version and steps to reproduce.
- **Security reports:** see [SECURITY.md](SECURITY.md) (please do not use public issues).
